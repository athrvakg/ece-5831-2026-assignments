# A_02 — Python NumPy Tutorial

**Course:** ECE 5831 — Pattern Recognition & Neural Networks
**Author:** Atharva Gujarathi

## Overview

This assignment completes the [CS231n Python NumPy Tutorial](https://cs231n.github.io/python-numpy-tutorial/), covering:

- NumPy
- Arrays
- Array indexing
- Datatypes
- Array math
- Broadcasting

## Files

- **`numpy-tutorials.ipynb`** — Jupyter notebook (completed in VS Code, not Google Colab) containing runnable, executed examples for each topic above: creating arrays, array-creation functions (`zeros`, `ones`, `full`, `eye`, `random`), slicing, integer/boolean array indexing, dtype handling, elementwise array math, dot products, aggregate functions (`sum`), transposing, and broadcasting (explicit loop vs. `np.tile` vs. native broadcasting, plus additional broadcasting applications like outer products).
- **`README.md`** — This file.

## How to run

1. Open this folder in VS Code.
2. Open `numpy-tutorials.ipynb` and select the `ece-5831-2026` conda environment as the kernel.
3. Run all cells (`Run All`) to reproduce the outputs.
